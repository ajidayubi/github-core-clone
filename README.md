A fast, single-binary GitHub-compatible git forge written in Go (stdlib only): git smart HTTP (upload-pack v2/v0, receive-pack v0, shallow fetch, thin-pack deltas), REST v3, GraphQL, and MCP over one deterministic in-memory store.

## Run it

```sh
node main.ts
```
